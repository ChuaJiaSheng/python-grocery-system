# Python Grocery Ordering System

A terminal grocery ordering application with product sorting, cart editing, discounts and checkout bill calculation.

**Technology:** Python.

## Run or inspect

Run from this project directory with Python 3:

```sh
python src/main.py
```

No third-party Python dependency is required. The program runs in a terminal and uses in-memory products and shopping cart data. Checkout is a simulation. The original coursework calculation uses 7% GST; this historical behaviour is preserved and is not current tax guidance. The original report identifies this as group coursework.

## Repository preparation

Source and required assets were organised from existing coursework. Build outputs and IDE state are excluded. Original reports, slides and course handouts remain in the separate full backup; they are not bundled for public upload. Real credentials and original database records are not included.
